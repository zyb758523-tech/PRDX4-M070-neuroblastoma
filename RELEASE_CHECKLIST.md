# Public release checklist

- [ ] All four authors approve public release and author order.
- [ ] Institutional affiliation spelling is confirmed.
- [ ] MIT License is approved by the authors/institution.
- [ ] Optional ORCID identifiers are added to citation metadata.
- [ ] Repository is scanned for credentials and non-public personal information.
- [ ] `__GITHUB_REPOSITORY_URL__` is replaced in all files.
- [ ] GitHub repository is public and Zenodo integration is enabled.
- [ ] GitHub release `v1.0.0` is published.
- [ ] Zenodo version DOI is recorded.
- [ ] `__ZENODO_VERSION_DOI_URL__` is replaced in the code-availability statement.
- [ ] The manuscript cites the same archived version used for analysis.
